## Prioritized implementation / checkpoints

6B: retain screen and camera coordinates byte-for-byte. Remove redundant projection work; use existing Application.time for idle animation (only keyframe clock ownership line changes, coordinate AST assertions retained). Make Time stoppable/visibility-aware, Sizes own resize/DPR listeners. Cache renderer quality settings; keep CSS3D at CSS viewport dimensions. Deduplicate disposal of remaining scene geometry/material/textures and explicitly release renderer/overlay/CSS, UI, resources and owned listeners/audio. Guard late resource callbacks. Avoid a global singleton reset unless complete reconstruction can be proven; teardown is idempotent, full re-init uses reload.

6C: manual native High/Balanced/Performance selector, default High so accepted appearance is preserved. DPR caps 2/1.5/1, shadows 1024/512/off, decorative overlay on/off/off. These are conservative resource budgets, not GPU benchmarks or device-quality guesses. No automatic FPS switching, storage or extra lights. Presets apply at frame boundaries without modifying CSS3D/projection/monitor input. Keep fans functional at every preset; reduce optional overlay cost first. Explain tradeoffs and preserve user choice through resize/context restoration.

6D: lightweight native mobile entry before dynamic importing Application at width <768, or <=1024 with coarse pointer. This is a presentation choice, never a GPU capability claim. Link uses existing validated inner URL resolver; no second content source or security changes. Optional Explore 3D loads the current app and retains narrow cinematic bypass. Provide a persistent direct-portfolio link for all users and context/WebGL failure recovery. At all target widths/landscape use native controls, touch targets, reflow and no gesture interception. Do not modify inner responsiveness.

6E: accessible rendering options and portfolio navigation/return controls, visible focus, touch targets and reduced-motion CSS. Use native links/buttons/select, concise status changes only. Handle both WebGL contexts lost/restored: stop rendering during loss, allow browser restore, reapply settings; provide explicit Reload/direct portfolio instead of automatic reload. Catch initialization failure and show usable standalone entry. Close owned audio/listeners/timers; clean UI listeners and avoid typewriter effects under reduced motion. Preserve START, intro, Skip, monitor focus, free camera and hardware states.

6F: production build, application/full tsc, diff, geometry/50-ray/compositor/bridge/camera/intro/hardware/UI/inner checks, plus new quality/DPR/context/teardown/entry-responsive tests. Update old hash expectations only for intentional Renderer changes and keyframe clock ownership (assert exact one-line keyframe change). Investigate historical declaration conflicts from installed source without package edits/blanket suppressions. Attempt installed browser tooling; if renderer fails, publish manual profiling/acceptance matrix with all unobserved GPU/rendered metrics unmeasured. Targets are 60 FPS capable desktops and usable ~30 FPS intentional mobile 3D, never claimed results.
